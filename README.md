# DevTrack 🚀

A Django-based developer productivity dashboard for tracking coding problems and daily development tasks.

## ✨ Features

- 🔐 User registration and authentication
- 📊 Personal productivity dashboard
- 💻 Coding problem tracker
- 🔎 Search coding problems
- 📝 Add and manage development tasks
- ✅ Mark tasks as completed
- 🗑️ Delete problems and tasks
- 👤 User-specific data
- 🗄️ SQLite database
- 📱 Responsive interface

## 🛠️ Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
